# 417BOOM

Static marketing site for [417BOOM](https://417boom.com) — web design, SEO, and growth systems for Springfield & Nixa, Missouri.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 4170
```

Then visit `http://localhost:4170`.

## Structure

- `index.html` — landing page
- `css/styles.css` — layout and visual system
- `js/app.js` — nav, scroll reveals, contact form UX
